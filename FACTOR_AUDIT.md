# Pressure-factor audit

| User-requested factor | Treatment |
|---|---|
| Required run rate, target, overs left, wickets | Measured before every ball |
| Recent scoring, dot streak, time since a wicket | Measured using earlier deliveries |
| Powerplay / middle / death overs | Phase-adjusted performance |
| Bowler economy, preceding boundaries or no-ball | Measured earlier in the innings |
| Carry-the-team and teammates struggling | Measured from prior runs and wickets |
| Opposition aggression, consolidation, survival | **Inferred scoreboard state**; not real thoughts |
| Strong/weak team and individual opponent | Historical pre-match rolling results |
| Knockout / qualifications | Knockout observed; prior league points/NRR **approximate only** |
| Captaincy and lower-order collapse | Captain IDs and batting order in match data |
| Previous poor form / fear of being dropped | Historic personal slump proxy; no genuine selection decision |
| Toss and venue | Pre-match venue history, toss result and choice |
| Exact chasing within 14 overs to qualify | Not measurable reliably; no official complete historic NRR ledger |
| Sledging | Not scored; verified incident reports not supplied |
| Injuries / medical fitness / domestic tournaments | Not scored without complete comparable evidence |
| RR-ground bonus | None in overall scoring. RR fit may be assessed separately. |

The user requested excluding Pakistan representatives for IPL-relevant analysis. This is not a stated official Round 1 requirement.
